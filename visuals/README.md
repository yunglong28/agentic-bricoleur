# The Agentic Bricoleur — visuals

Tutto il materiale del progetto in un'unica cartella (da `minor-index-atelier/bricoleur`). I PNG originali sono convertiti in JPG per il web; gli originali restano nell'atelier.

- `tavole/` — serie finale: 01–11, arena (a1–a5), gilda (g1–g5), pannelli Maciunas, panorami
- `bozze/` — folle simulate dopo Bruegel e Bosch; `bozze/giochi/` sei iterazioni di Giochi di bambini (`codice/bricoleur11.py`)
- `archivio/` — prima e seconda versione, anteprime per seme, fogli di contatto, flux scartate, metadati
- `riferimenti/` — immagini di riferimento
- `codice/` — gli script che generano le tavole (`python3 bricoleurN.py OUT`)

Galleria: https://yunglong28.github.io/agentic-bricoleur/
